The *Smart Internship Portal* helps students find suitable internship opportunities in one centralized platform. Students can register, log in securely, explore available internships, view internship details, manage their profiles, and submit applications.

Administrators can manage internship opportunities and monitor student applications through the admin module. The system uses backend APIs and database integration to store and manage application-related information efficiently.

## ✨ Features

- Student Registration and Login
- Secure User Authentication
- Internship Listing and Search
- Internship Details
- Online Internship Application
- Student Profile Management
- Admin Dashboard
- Add and Manage Internships
- Manage Student Applications
- CRUD Operations
- REST API Integration
- Responsive User Interface
